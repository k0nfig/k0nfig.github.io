# Adithyadev MR — Portfolio

A responsive portfolio built with HTML and CSS, hosted on GitHub Pages.

## Preview locally

Open `index.html` in a browser, or run this from the project directory:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Visit http://127.0.0.1:4173. Page content is in `index.html`. Typography, colour, spacing, and responsive rules are in `styles.css`.
