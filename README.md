# Adithyadev MR — Portfolio

A responsive portfolio built with HTML and CSS, hosted on GitHub Pages.

## Preview locally

Open `index.html` in a browser, or run this from the project directory:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Visit http://127.0.0.1:4173. Page content is in `index.html`. Typography, colour, spacing, and responsive rules are in `styles.css`.

## Blog

Open /blog/ in the local preview to see the post index. Copy
blog/_post-template.html when starting a new post, then fill in the
title, summary, and sections. Match the table of contents links to the
section IDs. Add a card to blog/index.html when the post is ready to
share. Remove the draft label and noindex tag when the post is final.
